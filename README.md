# Клёвый угол — интернет-магазин рыболовных товаров

Интернет-магазин снастей для рыбалки: удилища, приманки, лодки, одежда и аксессуары.

## Возможности
- Каталог из 12 товаров с фильтрами по категориям и сортировкой
- Корзина: добавление, удаление, изменение количества с пересчётом суммы
- Сохранение корзины в localStorage
- Форма оформления заказа с валидацией и подтверждением «Заказ создан!»
- Адаптивный дизайн: ноутбук, планшет, смартфон

## Технологии
Чистые HTML, CSS и JavaScript. Без фреймворков. Изображения — авторские SVG.
